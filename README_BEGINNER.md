# Vehicle Failure Management - Beginner Guide

## Requirements
- Python
- Visual Studio Code
- Project virtual environment

## Step 1: Open the project folder
Open the vehicle-failure-management folder in Visual Studio Code.

## Step 2: Activate the virtual environment
In PowerShell:

.venv\Scripts\Activate.ps1

## Step 3: Install dependencies
python -m pip install -r requirements.txt

## Step 4: Explore the notebooks
Open the notebooks folder and review the data preparation and model training notebooks.

## Step 5: Explore the Python scripts
Review the scripts inside src.

## Step 6: Review trained models
The models folder contains saved model files.

## Step 7: Review results
The reports folder contains model evaluation and explainability outputs.

Important:
Check the source code for the correct pipeline execution command
before running or retraining models.
