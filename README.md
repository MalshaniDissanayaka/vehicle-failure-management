# Vehicle Failure Management Using Explainable AI

## Project Overview
This project aims to develop an Explainable AI-based vehicle fault prediction and management system for the Toyota Aqua / Prius C.

## Objectives
- Analyse vehicle sensor data.
- Predict selected engine faults using machine learning.
- Explain predictions using SHAP and LIME.
- Visualize affected components in 3D.
- Provide role-specific alerts to drivers, technicians, and manufacturers.

## Current Progress
- Candidate datasets collected.
- Initial data cleaning completed.
- Dataset audit started.
- Fault labels and Toyota-specific technical thresholds are being verified.

## Technologies
Python, Pandas, Scikit-learn, XGBoost, SHAP, LIME, Streamlit.

## Data Notice
Dataset sources, licences, and any synthetic data will be documented. Simulated fault data will be clearly identified.

## Status
In development.
